# 2 第二层：为什么 perception 无法解决这个问题

这里要指出一个 **结构性限制**。

现代 perception pipeline：

```
pixel → feature → object category
```

但交通语义真正关心的是：

```
agents
intentions
interactions
possible futures
```

也就是说：

```
scene semantics ≠ image semantics
```

真正需要的是：

```
semantic reasoning over possible futures
```

而不是：

```
pattern recognition in images
```

这时你可以自然引出一个观察：> In practice, planners often operate under a simplified assumption:
> the perceived world is already semantically resolved.

但现实中：

```
semantic uncertainty is everywhere
```

例如：

```
car may yield
car may cut-in
pedestrian may cross
```

这不是 perception 可以直接解决的问题。
